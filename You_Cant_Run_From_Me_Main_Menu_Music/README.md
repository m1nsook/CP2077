# You Can't Run From Me — Main Menu Music

Replaces the main menu music with You Can't Run From Me by Sugar Trap Queen, from 102.0 HKGN FM.

[Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/39717)

## Requirements

- Cyberpunk 2077 2.50
- [Immersive Main Menu Audio 1.4](https://www.nexusmods.com/cyberpunk2077/mods/22695)
- [Audioware](https://www.nexusmods.com/cyberpunk2077/mods/12001) and its dependencies
- REDscript

## Installation

Use the complete release ZIP (with the audio included). Remove any other main menu music pack first, then extract the ZIP into the game directory. Only one pack registering `MainMenuMusic` can be active at once.

## Audio source

Original in-game asset: `833747382.wem`, identified using the game's audio metadata and soundbank and exported as WAV with WolvenKit. Original music rights belong to their respective holders.

The source repository contains only the configuration. For a local build, export the original asset as `you_cant_run_from_me.wav` and place it beside `audios.yaml`.

## Uninstallation

Remove this pack's `audios.yaml` and `you_cant_run_from_me.wav` from `r6/audioware/MainMenuMusic/`.
