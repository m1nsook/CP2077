# CP2077 Mods

[![License](https://img.shields.io/github/license/m1nsook/CP2077)](LICENSE)
[![GitHub Release](https://img.shields.io/github/v/release/m1nsook/CP2077)](https://github.com/m1nsook/CP2077/releases)

Source code and releases for my Cyberpunk 2077 mods.

## Mods

| Mod | Description | Status |
| --- | --- | --- |
| [No Tracking Please](No_Tracking_Please) | Blocks enemy netrunner/police position reveals and quickhack trace acceleration. | Active |
| [Free Chrome](Free_Chrome) | Sets standard cyberware Humanity/Capacity costs to zero with reversible Mod Settings and NSUI controls. | Active |
| [Camera Killer](Camera_Killer) | Shuts down cameras connected to the same network when V disables one camera. | Active |
| [NΣT — Iconic Cyberdeck](NEST) | Experimental standalone cyberdeck with a built-in network Infiltration quickhack. | Developer prototype — untested |
| [UndiscoverMe](UndiscoverMe) | Reveals eligible NCPD Scanner, Cyberpsycho and Tarot map markers without reopening completed activities. | Active |
| [UndiscoverMe Teleporter](UndiscoverMe_Teleporter) | Optional addon: hold the map's Fast Travel action on an UndiscoverMe pin to teleport. Requires UndiscoverMe core. | Active |
