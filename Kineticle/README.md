# Kineticle

Control the chassis collision mass of vehicles driven by V, with optional vehicle protection.

## Installation

Install the Core and one controller from the [release](https://github.com/m1nsook/CP2077/releases/tag/kineticle-v1.0.0).

| Package | Requirements |
| --- | --- |
| Core | Cyberpunk 2077 2.50, RED4ext 1.31.1 |
| M1 Arc Controller | REDscript, M1 Arc |
| NSUI Controller | REDscript, CET, Native Settings UI |
| Mod Settings Controller | REDscript, Mod Settings |

Install exactly one controller. Settings are configured in-game; no manual JSON editing.

- Chassis mass multiplier: 1–100×, capped at 100,000 kg.
- Master switch and motorcycle inclusion.
- Optional mechanical, body deformation and glass protection.

See [native implementation and compatibility notes](Native/README.md).
