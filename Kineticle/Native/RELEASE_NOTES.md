# Kineticle 1.0.0

Initial release for Cyberpunk 2077 2.50 (executable 3.0.88.46235) and RED4ext 1.31.1.

- Adjustable chassis collision mass, 1–100× (maximum 100,000 kg).
- Scoped to V's actively driven cars and motorcycles, with original mass restoration on leaving the vehicle.
- Optional mechanical damage protection, body deformation restoration and glass restoration.
- Persistent settings and a choice of M1 Arc, Native Settings UI or Mod Settings.
- No synthetic velocity corrections or shared vehicle record changes.

## Installation
Install **Core** and **exactly one** controller. Extract each selected ZIP into the Cyberpunk 2077 game directory.

- M1 Arc: REDscript and M1 Arc 1.0.1 or newer.
- NSUI: REDscript, CET and Native Settings UI 1.97.
- Mod Settings: REDscript and Mod Settings 0.2.35 for game 2.50.

Core's native DLL requires RED4ext only; a controller is required for the verified gameplay configuration and driver authorization. No manual JSON editing. Remove older development packages and previous controller before switching. Do not install controllers together.

The mass modifier can also affect collisions with environmental objects. Standalone authorization without a controller is not verified. Native mechanical damage interception has not been independently confirmed; tire and occupant protection are not included.

**Nexus Mods:** https://www.nexusmods.com/cyberpunk2077/mods/39702
